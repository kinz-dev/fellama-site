Privacy policy

TCN Live Scheduler, the scheduling tool of the 譚仔新聞 (TCN) station. Effective 7 October 2026.

Who uses it

The TCN Live Scheduler is used only by the owner of the TCN YouTube channel, to run that channel's live broadcasts. It is not offered to the public, and nobody else signs in to it.

What it accesses

When the channel owner signs in with Google, the tool asks for the YouTube scope (https://www.googleapis.com/auth/youtube). With it, the tool:

  • reads the channel's name and its live stream settings, to find the stream the station sends to;
  • creates, updates, starts, ends and deletes the channel's own live broadcasts, one for each programme;
  • sets each broadcast's title, description, category and content labels, such as the disclosure that it contains altered or synthetic content.

It does not read viewers' data, comments, messages or any other account's information, and it does not upload or change videos other than the broadcasts it creates.

What it keeps, and where

The sign-in token Google issues is stored in one file on the station's own computer, readable only by the owner's account. Records of which broadcasts were made and when are kept on the same computer, for the station's schedule. Nothing is stored on any other server.

Sharing

Google user data is not sold, shared or transferred to anyone, and is not used for advertising or for training any model. It is used only to run the TCN channel's live broadcasts as described above.

The TCN Live Scheduler's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The channel owner can revoke the tool's access at any time at myaccount.google.com/permissions. Deleting the token file on the station's computer removes the stored sign-in.

Changes and contact

If this policy changes, the new version is published on this page with a new effective date. Questions can be sent to the TCN channel through its YouTube page.
